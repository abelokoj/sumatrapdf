Make yourself at home.

A few small steps to a more personal reading space.

  1. Open your first document

    Install the reader or launch the portable EXE. Open a PDF, ebook or comic, then explore Settings → Appearance to choose your theme and interface font.

  2. Keep a word worth knowing

    Select a word, press Shift+D and save it with its meaning and context. Visit the home learning hub to review your vocabulary or study a bundled pack.

  3. Put a thought on the page

    Choose a PDF pen profile, color and width. Pin the combinations you use often, then save your PDF to keep its annotations for later editing in Enhanced.

A few things to know.

How is this different from the original SumatraPDF?

Enhanced is an independent fork. It adds offline dictionary lookup, vocabulary practice, pen profiles, pinned annotation presets, a temporary laser pointer and expanded appearance controls. Native annotations, search, document inversion and reference previews come from the upstream foundation. See the recorded upstream snapshot.

Can I use the dictionary and learning tools offline?

Yes. The installer and standalone portable EXE include an offline dictionary. You can import supported WM JSON/gzip, TSV and StarDict dictionaries. Additional pack downloads and updates are explicit; lookup and practice stay offline.

Which download should I choose?

Choose x64 for most Intel and AMD Windows PCs, or ARM64 for Windows on ARM. The installer provides a normal installation. The portable EXE runs directly. The portable ZIP contains the reader, dictionary data, license notices and optional shell integration helpers.

What should I know about the current release?

Advanced handwriting recognition and cleanup are not available. Laser behavior and pen responsiveness are still being refined. Reference previews require supported local destinations. Optional upstream AI, manual and CHM browser integrations need WebView2. Read the release notes.

Where can I report a problem or help with development?

Open a GitHub issue with the Enhanced version, Windows version, architecture and steps to reproduce. For pen issues, include the device and stylus model. The repository README covers development and builds.
