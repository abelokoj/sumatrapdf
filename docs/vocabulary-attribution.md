# Vocabulary sources

The bundled study decks use word lists from [Wasi Master / wordcheck](https://github.com/wasi-master/wordcheck), mirrored in [wmkeyboard-data](https://github.com/wasi-master/wmkeyboard-data/tree/master/vocab/sources/lists), under the MIT license, Copyright (c) 2026 Wasi Master. The full notice is in `docs/licenses/vocabulary-wordlists-MIT.txt` (also in `data/vocabulary/LICENSE`). `data/vocabulary/manifest.json` records exact source files and SHA-256 checksums.

The decks contain words and list names only. No proprietary study-guide definitions, examples or book text are included. Bundled meanings come from the corresponding WM vocabulary packs: Wiktionary via kaikki.org (CC BY-SA 3.0) and WordNet (WordNet License). Exact complete attribution blocks and source SHA-256 hashes are preserved in `data/vocabulary/pack-attributions.json` and packaged `docs/licenses/vocabulary-pack-attributions.json`; original compressed packs are retained alongside. Only definitions are included in the compiled learning data; quotations, audio and other supplemental text are omitted. WordNet is also available as an offline fallback. Publishers' names identify the study lists and do not imply affiliation.

The reference application [WM Keyboard](https://github.com/wasi-master/wmkeyboard) uses Leitner and SM-2 flashcards and word-of-the-day activities. This implementation is native Windows code. Meaning-choice, word-choice, spelling, scrambling and matching are additional practice modes, not claims about games offered by that reference. The source application is MIT licensed; no Kotlin implementation has been copied.

Imported WM vocabulary files may contain Wiktionary text under CC BY-SA 3.0 or other separately licensed material. Import preserves each pack's source and attribution metadata in the exported personal vocabulary file; keep those notices when sharing. Import only material you can use and redistribute.

Wiktionary-derived compiled meanings in `src/VocabularyMeanings.h` remain under CC BY-SA 3.0, independently of the GPLv3 application code. Changes: extracted the all original definition senses, joined with newlines, normalized word keys, and deduplicated words across study lists. Full license: https://creativecommons.org/licenses/by-sa/3.0/legalcode . Original authors and source URLs are listed in the preserved attribution blocks; WM Keyboard data compilation is by Wasi Master.
Dictionary downloads and updates are served from the SumatraPDF Enhanced repository: original WM packs in `data/vocabulary` and WordNet files in `src/dictionaries/wordnet-en`. The original compressed packs, attribution blocks and source hashes are retained. Explicit downloads do not replace the bundled offline lookup capability.
