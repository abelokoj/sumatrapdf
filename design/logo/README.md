# Application logo

The green logo is the approved SumatraPDF Enhanced logo. It appears in the reader, home page, dialogs, installer and PDF file associations. The repository home page displays the same artwork.

The raster master is [SumatraPDF-Enhanced-green.png](../../src/gfx/SumatraPDF-Enhanced-green.png). Application, PDF document, installer and store icons are derived from this master.

The [archive](archive) retains the blue, violet and coral alternatives and previous logo assets for reference. These alternatives are inactive and are not used by the application.
